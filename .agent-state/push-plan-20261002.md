### 残課題（レビュー指摘。今回の push が原因ではない）
1. **【ユーザー作業】I8 の鍵の設定**（これが済むまで H-1「Vercel の IP で全員が締め出される」は未解消）。手順は docs/ops/admin-operations.md「署名付き中継IPの鍵」。
   Render の `CLIENT_IP_RELAY_SECRETS` → 手動デプロイ → /readyz の `client_ip_relay=true` → Vercel の `CLIENT_IP_RELAY_SECRET`（Production・Sensitive）に同じ値 → 再デプロイ。
2. security M-1: Cloudflare Pseudo IPv4（240.0.0.0/4）が IP 軸のスキップ側に分類される。Render が AAAA を有効にする前に直す（240/4 は通常の IPv4 として数える）。
3. security M-2: 他人のメールを知っていれば 15 分ごと 5 回の誤入力でログインを締め出せる（以前からある）。端末 Cookie などで緩和。
4. QA M-1: 回数制限は単一プロセス前提。`WEB_CONCURRENCY>1` やスケールアウトで上限が N 倍に緩む。起動時 WARNING とテストを足す。
5. QA M-2: 業者申込の上限が DB 集計からメモリ集計に変わり、再起動で 0 に戻る。失敗した要求も数える。DB 集計の併用を検討。
6. QA M-3: `password_attempt` の同時送信テストは login 2 本のみ。account_delete か password_change に同じ待ち合わせハーネスを。
7. 旧査定のテーブル・画像（assessments / defect_evidences）が本番に残っているか確認し、不要ならマイグレーション先行の 2 段階で削除。
