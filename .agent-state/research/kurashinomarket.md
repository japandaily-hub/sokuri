# くらしのマーケット（運営：みんなのマーケット株式会社）成長データ調査

## 重要な事実訂正
課題原文では運営会社を「空株式会社」としているが、一次情報を確認した限り、くらしのマーケットの運営会社は
**みんなのマーケット株式会社**（Minna no Market Co., Ltd.、代表取締役 浜野勇介、非上場）であり、
「空株式会社」という社名は確認できなかった（社名変更の事実も確認できず）。
検索でヒットした「株式会社 空感」はくらしのマーケット上の一出店事業者（さいたま市）であり、運営会社とは無関係。
以下は運営実体である「みんなのマーケット株式会社」についての調査結果として報告する。

## 1. 創業・サービス開始年
- 法人設立: **2011年1月17日**（みんなのマーケット株式会社、資本金1億円、代表取締役 浜野勇介） — 出典: https://minma.jp/
- サービス「くらしのマーケット」開始: **2011年** — 出典: https://markelabo.com/n/n537775f3f080
- 2018年時点のインタビューで創業者本人が「創業して今年で8年」と発言（→事業構想・準備は2010年から）— 出典: https://thebridge.jp/2018/03/interview-yusuke-hamano-at-bdash-fukuoka
  ※法人登記(2011/1)と発言（2010起点）に1年のズレがあるが、いずれも一次情報として併記する。

## 3. 成長速度の要約
- 事業者数: 2018年3月(15,000社) → 2019年12月(33,000社) … 約1.75年で2.2倍（年率換算 約38%/年、単純CAGR）
- 事業者数: 2019年12月(33,000店) → 2022年半ば頃(70,000店) … 約2.5年で2.1倍（年率換算 約32%/年）
- 事業者数: 2022年(70,000店) → 2023年頃(90,000店) → 現在(100,000店超) … 緩やかに逓減する増加ペース（急拡大期は創業〜2020年前後、その後は安定成長フェーズに移行したとみられる）
- 流通額（GMV）は2018年3月の「年間50〜60億円」以降、公表数値が一切見つからず、経年推移は追跡不能。
- 売上高は一次情報として2018年3月の「月商1億円」発言が唯一。これ以外の年次の売上高・手数料収入は非開示で、資金調達時のバリュエーションからの逆算推定値も報道等で見つからなかった。
