# カタヅケ ロゴ調整案（現行テーマ整合）— 2026-09-04

## 前提（一次情報で確認した現行デザイン）
- 書体: Noto Serif JP 400（明朝）＋ 英字 Montserrat 600（`web/src/app/layout.tsx`）
- 色: 主色 `--primary #1447e0`（青）／墨 `--ink #20242e`／罫 `--line #dce3ea`（`web/src/app/katazuke.css :root`）。苔色 #527e52 は 2026-09-03 の a492bc9 でユーザー指示により青へ変更済み。
- かたち: `--radius 0`・影 none・UIアイコン `.ic` は stroke 1.5 / 24 = 6.25%
- ロゴ運用: ヘッダー・フッター・OG は文字ワードマーク `KdzLogo`（「カタヅケ」＋「KATAZUKE」）。旧 PNG（紺 #1e2a44＋金 #e8b923・太線 9%・丸角）は `web/src/app/icon.png`（32px）と `apple-icon.png`（180px）に残存し、現行テーマと唯一配色がずれている。

## 調整内容（旧 PNG → ベクター再作成）
| 項目 | 旧 | 提案 | 根拠 |
|---|---|---|---|
| 配色 | 紺＋金 | 墨 #20242e ＋ 青 #1447e0（A） | 現行トークンのみ使用。金は現行パレット外の暖色で混色源になる |
| 線幅 | 約 9% | 7% | UIアイコン 6.25% と同階級〜半段上。5.5% は査読で「ナビアイコンに負ける」と判定 |

| 形式 | PNG のみ | SVG マスター＋PNG | 拡大・再配色・ダーク反転に耐える |

## 配色バリエーション
- **A 墨＋青（推奨・単独露出のマスター）**: ファビコン・apple-icon・OG・LINE プロフィール画像。
- **B 墨 単色**: ワードマークと横に並べる場合はこちら（青は英字 KATAZUKE が担うため、アイコンまで青いと主色の意味が薄まる）。
- **C 青 単色**: 白地ヘッダーでは LINE 緑 CTA と張り合い、「青い家＝押せる要素」に誤読されるため不採用。反転面のみ。
- **D 墨＋金**: 参考。現行パレット外の暖色で非推奨。
- **E 白抜き（青地）／F 白抜き（墨地）**: 業者バナー・CTA 帯・フッター用。ネクタイは白、結び目に地色。

## ロックアップと配置
- ヘッダー: 現行の文字のみ運用を維持するのが第一候補。査読では「顔（目＋蝶ネクタイ）はキャラクターの記号で、明朝・角丸0で作った静けさにマスコット性を戻す」と指摘。入れるなら B（墨単色）を 22px ワードマークの左に、高さ 1.75 倍・gap 10px。
- モバイル 60px: アイコン＋二段ワードマークは左塊が約 50px 増えるため、アイコン単独かワードマーク単独のどちらかにする。
- SVG をインライン展開する場合: `clipPath` の id を要素ごとに一意にする（React なら `useId`）。ワードマーク隣に置く時は `aria-hidden="true"`。

## ファビコン
- 16px では線画版の目・ネクタイが潰れるため、`favicon_A_solid`（面塗り・目なし・白ネクタイ＋青結び目）を 16/32px に使い、48px 以上は線画版 A を使う。
