## 1. ご相談の目的と、結論として伺いたいこと

カタヅケは現在β期間中で、手数料を受け取っていません。成約業者から手数料（買取金額の8%・税別）を受け取り始める前に、次の4点についてご判断をいただき、必要な届出・規約・画面表示を整えたいと考えています。

1. 現在の入札の仕組み（他社の入札額を匿名で表示し、業者が金額を引き上げられる）は、古物営業法の「古物競りあっせん業」に当たり、公安委員会への届出が必要か。
2. 買取代金をカタヅケ経由で受け渡す形にした場合、資金移動業の登録などが必要か。現在の「当事者間で直接精算」を続ける場合と比べてどうか。
3. 業者が依頼者の自宅で買い取る取引に、特定商取引法の「訪問購入」の規定（クーリング・オフ、書面交付、不招請勧誘の禁止など）がどう及ぶか。カタヅケ自身に義務が及ぶか。
4. 以上を踏まえ、手数料を実際に請求し始める前に、何を（届出・規約・表示）しておくべきか。

## 3. 論点ごとの整理

### 論点1　古物営業法「古物競りあっせん業」の届出

#### 事実（実装から）

- **入札は1業者につき1件**。入札額は出品物すべての買取総額。
- **引き上げ**：業者は、依頼者が業者を選ぶまでの間、自社の入札額を引き上げられる。引き下げはできない。1回あたり1,000円以上、1件の入札につき20回まで。
- **業者に見える情報**（承認済みの業者に、案件が入札受付中の間だけ）：
  - 他社の入札それぞれの金額、引き上げた回数、更新日時（社名・コメント・業者IDは出さない）
  - 現在の最高額と入札社数
  - 自社が最高額か、他社が上回っているか、その差額
- 成約後・キャンセル後は、他社の金額は業者に一切表示しない（落札額を後から知らせない）。
- 停止中・退会済みの業者の入札は、他社への表示や最高額の計算に含めない。
- **依頼者に見える情報**：全入札の社名・口コミ・金額・メッセージ。最高額の入札には「最高額」の印が付く。
- **決め方**：最高額が自動で落札になるのではなく、**依頼者が任意の1社を選ぶ**。
- **入札期間**：上限なし。依頼者が業者を選んだ時点で終わる。依頼者はいつでも出品を取り下げられる。入札が付いてから2日たっても選んでいない依頼者には、選択を促すリマインドを送る（入札ゼロのまま3日たった案件にも別のリマインドを送る）。
- 依頼者の自己申告で案件が作られ、写真とAI要約で入札が行われる。現物の確認は訪問時。
- 経緯：他社の金額を業者に**見せない**設計にしていた時期があります（入札件数と自社の入札のみ表示）。2026年9月7日に、価格競争を働かせる目的で現在の表示に切り替えました。**表示の有無はシステム上切り替え可能**です。
- 手数料は現在0円（上記2-4）。

#### 当方の現状の理解

- 古物営業法第2条第2項第3号の「古物競りあっせん業」に当たると、営業開始の日から2週間以内に公安委員会へ届出が必要（同法第10条の2）と理解しています。
- 社内の検討では、判断の要素を「①売り手と買い手のあっせん」「②競りの方法（買い手どうしが互いの条件を知りうる状態で、最も有利な条件の者を決める）」「③営業として行う（対価を受ける）」と整理しました。ただしこれは社内の要約で、条文と政令の要件そのものを確認できていません（条文の文言・政令で定める「競りの方法」の中身は要確認）。
- ②については、他社の金額と順位を業者に見せ、引き上げを認めている現在の形は、「競り」に近いと考えています。一方、落札者を決めるのは依頼者の自由な選択で、最高額が自動で決まる仕組みではありません。
- ③については、手数料を受け取り始める時点で状況が変わると考えています。

#### 確認したいこと

1. 現在の入札の仕組み（他社の金額・最高額・順位・社数を匿名で表示し、引き上げを認める）で手数料を受け取った場合、「古物競りあっせん業」に当たりますか。
2. 依頼者が最高額以外の業者も自由に選べる点は、該当しないと判断する材料になりますか。
3. 他社の金額・最高額・順位を業者に見せない形（入札件数と自社の入札のみ表示）に戻せば、該当しないと判断できますか。引き上げの仕組みを残すかどうかで結論は変わりますか。
4. 入札期間に上限がない（依頼者が選ぶまで続く）ことは、判断に影響しますか。
5. 手数料を受け取らないβ期間中の運営は、届出の対象外と考えてよいですか。
6. 届出が必要な場合、「営業開始の日」はいつと考えるべきですか（手数料の請求開始日か、サービス公開日か）。届出後にカタヅケが負う義務（努力義務を含む）を教えてください。
7. 買い手である業者が全員古物商許可を持っていることは、判断や届出後の義務に影響しますか。

### 論点2　資金決済法（代金をカタヅケ経由で受け渡す場合）

#### 事実

- 現在は案Aのみ。カタヅケは代金を預からず、振込もしない（2-4）。
- 代金の向きは **業者（事業者）→ 依頼者（個人）**。受け取る側は、事業としてではなく家庭の不用品を売る個人です。
- 1件の買取金額の上限は設けていません。高額品（骨董品等）が混じる可能性は否定できません。現時点の平均・最高の成約額は、正式な実績としてはまだありません（未確認）。
- 手数料は業者からもらう予定で、その請求方法は未決定（2-4）。

#### 当方の現状の理解（社内の条文整理による。原文の照合は社内で実施済みだが、法的判断ではない）

- 資金決済法第2条の2は、受取人から委託を受けて債務者から資金を受け入れ（または他の者に受け入れさせ）、受取人に引き渡す行為のうち、一定のものを為替取引とみなすと定めていると理解しています。その第1号は「受取人が個人（事業として受取人となる場合を除く）」であることなど、内閣府令（資金移動業者に関する内閣府令第1条の2）で定める要件によります。
- 内閣府令第1条の2は、受取人が個人であり、かつ一号・二号・三号の**いずれか**に当たる場合を定めていると読んでいます。その中で当方が特に気にしているのは、
  - 一号：資金を受け入れた時点までに、業者の依頼者に対する支払債務が消滅しないもの
  - 二号：立替払いなど信用供与による債権の回収
  - 三号：エスクロー的な預かりや、契約成立に不可欠な関与をするプラットフォームの場合などを除外する規定（イ〜ニ）
  - です。エスクロー型であっても三号から外れるだけで、一号に当たれば為替取引になり得る、と理解しています。
- したがって案Bでは、カタヅケに資金移動業の登録（同法第37条）が必要になる可能性が高いと考えています。登録には種別（1件100万円以下の第二種など。同法第36条の2・施行令）がある、と理解しています。
- 「受取人の受領代理人としてカタヅケが受け取った時点で業者の債務が消滅する」と規約で定める方法もあり得ますが、依頼者がカタヅケの倒産等のリスクを負うことになり、利用者保護の趣旨に反して否認される恐れがあると考え、採用に慎重です。
- 案Cは、PSPが自らの名で登録済みの資金移動業者（または銀行）として受け渡し、カタヅケが資金を受け入れる主体にならなければ、カタヅケの登録は不要になり得ると考えています。ただし、PSPの残高にカタヅケ名義でプールする形では「他の者に受け入れさせ」に当たり得ると理解しています。候補のPSPが日本で資金移動業の登録を持つか、「受取人が非事業の個人」の取引を扱えるかは**未確認**です。
- 資金決済法第2条の2は、現金の交付を受けて現金を交付する行為を除外している、と社内で確認しています。訪問先での現金払い（案A）はこの点でも問題が小さいと考えています。
- 出資法第2条（預り金の禁止）にも留意が必要と考えています。
- 古物営業法施行規則第15条第3項は、非対面の本人確認の方法として「相手方本人名義の預貯金口座への振込み」で代金を支払うことを約する方法（第6号・第7号）を定めています。カタヅケやPSPを経由した振込でこれが満たされるかは**未確認**です（主に対面での買取を想定しているため、現状は影響が小さいと考えています）。

#### 確認したいこと

1. 案B（業者→カタヅケ→依頼者）は、資金決済法上の為替取引に当たり、資金移動業の登録が必要ですか。
2. 案Bで、カタヅケが手数料を差し引いて残りを依頼者に渡す場合、結論は変わりますか。
3. 案C（PSP経由）で、カタヅケが登録不要となるための条件（契約関係・資金の名義・指図の範囲）を教えてください。PSPから取り寄せるべき資料は何ですか。
4. 案A（当事者間の直接精算）のまま、業者の「振込済み」報告と依頼者の「受取済み」確認を画面で記録・表示するだけなら、登録は不要と考えてよいですか。
5. 業者の未払いに備えて、(a) カタヅケが自らの負担で一定額を依頼者に補償する、(b) 業者から保証金を預かる、という方法は、資金決済法・出資法の点で問題になりますか。
6. 業者から手数料を受け取ることだけ（代金には触れない）は、これらの法律の点で問題がないと考えてよいですか。

### 論点3　特定商取引法「訪問購入」

#### 事実

- 買取は、業者が依頼者の自宅（依頼者の指定場所）を訪問して行う。
- 訪問は、依頼者が自ら出品し、業者を選び、業者が出した候補日から依頼者が日程を確定した後に行われる（2-3）。業者から依頼者へ事前に連絡する手段は、選ばれた後のチャットのみ。
- 入札額は写真に基づく参考値で、最終額は現物確認後に決まる（利用規約第4条）。現場での減額は、理由を示して依頼者の同意を得た場合のみ（業者規約第5条、システム上も依頼者の承認制）。つまり、**最終的な売買の合意は訪問先で成立する**場合が多いと考えています。
- 出品物は家財全般（家具・家電・書籍・CD/DVD・衣類・骨董品等が混在し得る）。品目の制限は「法律上売買が許可されているもの」のみ。
- 法定書面の作成・交付は業者に任せており、カタヅケは書面のひな形を提供していない。業者が書面を交付したかをカタヅケは確認・記録していない。
- 成約後のキャンセルは、完了前なら画面からどちらでもできる。完了後の返品は当事者の合意による、と表記している。
- 現在の規約・表示の文言（抜粋。全文は添付）：
  - 利用規約第8条：「訪問による買取には特定商取引法（訪問購入）の規定が適用される場合があります。クーリング・オフの可否は、品目（家具・家電等は対象外）や契約に至った経緯（ご自身の依頼で業者が訪問した場合は対象外となることがあります）によって異なります。」「本条は、法令によりユーザーに認められる……権利を制限するものではありません。」（同趣旨の文言がFAQ・訪問日程の画面にもあります）
  - 特定商取引法に基づく表記：「支払い方法・支払い時期：成約後にご案内します。」（2026-09-25 に、決済方針が決まるまで断定しない表現へ変更。それまでは「引き取り完了時に業者と直接精算」「当社は代金を預からない」と表記していました）「業者を選択した後のキャンセルは、業者との合意が必要です。」「クーリング・オフの可否を判断し、書面で告知するのは、訪問した登録業者です。」
  - 業者規約第7条：法定書面の交付、クーリング・オフへの適切な対応を求め、違反は即時登録停止。
  - 同表記ページの冒頭に「特定商取引法第11条および第58条の2に基づき」と書いています。

#### 当方の現状の理解（社内検討メモによる）

- 出張買取は訪問購入（特定商取引法第58条の4）に当たり得ると理解しています。その場合、業者には、氏名等の明示・不招請勧誘の禁止（第58条の5・第58条の6）、申込時・契約時の書面交付（第58条の7・第58条の8）、書面受領日から8日間のクーリング・オフ（第58条の14。依頼者に不利な特約は無効）、クーリング・オフ期間中の物品の引渡しの拒絶（第58条の15）、第三者へ引き渡した場合の通知（第58条の11）などの義務がかかると理解しています。
- 依頼者の請求で業者が訪問した場合の適用除外があると社内メモにはありますが（第58条の17第2項第1号と記載。原文は未照合）、見積もりの依頼や案件の投稿が「請求」に当たるかは、分からないままです。
- 政令で対象から除かれる物品があると理解していますが、どの品目かは確認できていません。規約の「家具・家電等は対象外」という例示が正しいかも確認できていません。
- これらの義務を負うのは購入業者で、カタヅケは取引の当事者ではないため、直接の義務者ではないと考えています。ただし、カタヅケの表示や仕組みが業者の義務違反を招いたり、依頼者の権利を制限したりする形になっていないかは、別に気にしています。
- 実際の運用（引き取り完了時に業者と精算）と、8日間のクーリング・オフ・引渡拒絶の関係が整理できていません。

1. カタヅケ経由の出張買取は、訪問購入に当たりますか。
2. 依頼者が自ら案件を作り、業者を選び、訪問日を確定して業者が訪問する形は、「依頼者の請求による訪問購入」として適用除外（クーリング・オフ等を含む）に当たりますか。当たる場合、どの規定が除外され、どの規定が残りますか。

### 論点4　手数料（8%）を請求し始める前に必要なこと

#### 事実

- 手数料は成約業者に請求する予定（依頼者は無料）。料率は業者に個別に通知する（業者規約第3条）。請求開始の時期は未定。
- 手数料の計算・請求の仕組みはまだ作っていない（2-4の未確認事項）。

#### 当方の現状の理解

- 手数料の受け取りを始めることで、論点1（届出）の判断が変わる可能性があります。
- 代金に触れない限り、論点2の登録は不要と考えています。
- 手数料を「成約時」に発生させると、その後のキャンセル・クーリング・オフ・減額との関係の整理が必要になると考えています。

#### 確認したいこと

1. 請求開始までに必要な届出・手続は何ですか（論点1の届出以外に、ほかに必要なものはありますか）。
2. 手数料の計算の基準（落札額／減額後の確定額）と発生時点（成約時／完了時／クーリング・オフ期間経過後）について、法的に望ましい設計はありますか。クーリング・オフや解除があった場合、手数料は返すべきですか。
3. 業者規約・利用規約・特定商取引法に基づく表記で、請求開始前に必ず直すべき箇所はどこですか（添付の全文をご確認いただけると助かります）。
4. 手数料が業者の買取額に上乗せ（依頼者への提示額の引き下げ）される形になる場合、依頼者向けの表示で注意すべきことはありますか。

## 4. すでに取っている対策

- **代金に触れない**：現在の運用では代金は当事者間で精算し、カタヅケは預からない・振り込まない。ただし決済方針が未決定のため、2026-09-25 から画面・表記ページでは「お支払い方法は成約後にご案内します」とし、代金の流れを断定していない。依頼者の口座情報は業者へ自動で開示しない。
- **業者の参加条件**：古物商許可番号の入力が必須。許可証画像の提出と運営の承認がなければ入札できない。規約違反・許可失効時は停止・取消（業者規約第8条・第9条）。
- **個人情報の段階的な開示**：査定段階では地域（市区町村まで）と品物の情報のみ。成約した1社だけに詳細住所と連絡用メールを開示。氏名・電話番号は業者に渡さない。
- **営業連絡の抑制**：業者が依頼者に連絡できるのは選ばれた後だけ。入札メッセージ・業者紹介文に連絡先やURLを書けない。
- **一方的な減額の禁止**：減額は理由を付けた申請と依頼者の承認が必要（1取引2回まで）。
- **特定商取引法への配慮**：業者規約で法定書面の交付・クーリング・オフ対応を義務付け。利用規約でクーリング・オフ等の法定の権利を制限しない旨を明記。クーリング・オフの可否を断定しない文言にしている。
- **入札表示の配慮**：他社の社名・コメントは業者に出さない。成約後は他社の金額を出さない。
- **手数料**：β期間中は0円（システム上も0円固定）。料率は公開ページに載せず、業者に個別通知とした。
